# Código fuente del proyecto EH2025

## Descripción
Esta carpeta está destinada a organizar los scripts modulares del proyecto de análisis de microdatos de la Encuesta de Hogares 2025.

## Componentes previstos
- Limpieza y transformación de datos.
- Ingeniería de características.
- Entrenamiento de modelos de Machine Learning.
- Evaluación y generación de resultados.

## Implementación actual
El procesamiento, análisis exploratorio y entrenamiento de modelos del Caso 1 se encuentran documentados en el notebook ubicado en `notebooks/`.

## Reproducibilidad
Los procedimientos se desarrollan mediante Python, DuckDB y bibliotecas de análisis de datos y Machine Learning.
