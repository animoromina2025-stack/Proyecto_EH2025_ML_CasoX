# Notebooks – Proyecto EH2025

## Descripción

Esta carpeta contiene los cuadernos de análisis desarrollados en Python para el proyecto académico de la Encuesta de Hogares 2025 (EH2025), correspondiente al Caso 1: análisis de la inasistencia escolar en Bolivia.

## Notebook disponible

**Archivo:** `Caso_1_Desercion_Escolar_EH2025.ipynb`

### Contenido del notebook

1. Conexión y consultas a la base de datos DuckDB.
2. Exploración y validación de microdatos.
3. Limpieza y transformación de variables.
4. Análisis exploratorio de datos (EDA).
5. Construcción del conjunto de datos analítico.
6. Entrenamiento de modelos Random Forest y XGBoost.
7. Evaluación del rendimiento de los modelos.
8. Análisis de importancia de variables.
9. Generación de gráficos y visualizaciones interactivas.

## Tecnologías utilizadas

- Python
- Google Colab
- DuckDB
- Pandas y NumPy
- Scikit-learn
- XGBoost
- Plotly y Folium

## Ejecución

El notebook fue desarrollado en Google Colab. Su ejecución completa requiere disponer de los microdatos EH2025 y de la base DuckDB en un entorno privado autorizado.

## Seguridad de la información

Los microdatos originales, la base DuckDB y sus respaldos no forman parte de este repositorio público.
