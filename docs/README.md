# Documentación del proyecto EH2025

Esta carpeta reúne la documentación técnica y metodológica del proyecto de análisis de la Encuesta de Hogares 2025 de Bolivia.

## Contenido previsto

- Descripción del problema de investigación.
- Metodología de procesamiento y análisis.
- Diccionario de variables utilizadas.
- Descripción de los modelos de Machine Learning.
- Evaluación de resultados.
- Conclusiones y recomendaciones.

## Objetivo

Documentar el proceso de análisis de la inasistencia escolar en Bolivia, garantizando la trazabilidad y reproducibilidad del trabajo.
